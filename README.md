# JAVANSH

### Java Algorithm & Performance Analysis Platform

**Write. Run. Analyze. Optimize.**

JAVANSH is a Java-based platform designed to help developers understand code execution, analyze algorithm performance, compare solutions, and identify optimization opportunities.

## Core Modules

* **Code Execution Visualizer** — Understand program execution step by step.
* **Complexity Lab** — Analyze algorithm performance across different input sizes.
* **Code Battle** — Compare multiple implementations by execution time and memory usage.
* **Code Intelligence** — Identify inefficient coding patterns and explore possible optimizations.

## Tech Stack

* Java
* Spring Boot (planned)
* MySQL (planned)
